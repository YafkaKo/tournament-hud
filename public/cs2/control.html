«Карта сыграна» берёт счёт из игры, отмечает победителя в списке карт и прибавляет ему очко серии.

Стороны CT / T

Данных из игры пока нет

Нужно только для самой первой карты. Сервер запоминает игроков по Steam ID и дальше сам знает, где какая команда: смена сторон в перерыве, в овертайме и на следующих картах серии отрабатывается без вас. Если сервер CS2 знает названия команд (mp_teamname_1 / _2) и они совпадают с названиями здесь — берутся они.

Заставки

Таймер «Матч скоро начнётся» Alt+C

Поверх любой сцены. На заставке «Скоро начнём» — крупно по центру. Скрытие не сбрасывает отсчёт.

Комментаторы Alt+K

Итог карты — заставка Alt+5

Победитель подставляется сам после «Карта сыграна». Счёт карты — из списка карт серии.

Trivia Alt+T Alt+N

Плашка «Знаете ли вы» поверх любой сцены — заполнить паузу. Можно заготовить факты списком (по одному на строку, заголовок и текст через «|») и листать их кнопкой или Alt+N.

Фоны сцен

Картинка 1920×1080 (PNG, JPG, WebP, GIF) заменяет фон сцены. «Только картинка» прячет текст — весь дизайн берётся из изображения; таймер и Trivia остаются поверх. Файлы ложатся в public/assets/backgrounds.

Турнирная сетка Alt+4

JSON: массив раундов, в каждом — матчи с двумя сторонами. Формат тот же, что у HUD для Dota 2.
