# HUD трансляции Dota 2 и CS2

Оверлей для студенческого турнира: графика поверх игры, заставки, турнирная сетка,
итоги карты, вероятность победы, реклама в паузе, анимация пика и пульты, с которых
всё это переключается прямо в эфире.

**Одна программа на обе игры.** Один сервер, один оверлей в OBS, один пульт. Какая игра
сейчас в эфире — выбирается на пульте. Названия команд, счёт серии, тексты, фоны и реклама
общие: ввели один раз — работает в обеих играх.

Работает на ваших компьютерах в локальной сети. Без аккаунтов и подписок.
Интернет нужен только для иконок и анимаций героев (серверы Valve) и для догрузки итогов
карты Dota из OpenDota — без него всё работает, просто без этих вещей.

---

## Как это устроено

```
   Dota 2 / кастомка Arena 5x5 / CS2 (клиент наблюдателя)
        │  ~10 раз в секунду шлёт состояние матча
        ▼
   http://<ПК с сервером>:3000/gsi      ← игра определяется по самому пакету
        │
   Сервер (Node.js)
        ├─ games/dota — склейка снимка, итоги, вероятность, OpenDota, пики драфта
        ├─ games/cs2  — стороны по Steam ID, раунды, ADR/HS%, бомба
        └─ core       — общее состояние, быстрые действия, фоны, реклама, анимация пика
        │
        ├──► overlay.html      → OBS, источник «Браузер»: HUD игры в эфире + реклама + пики
        ├──► control.html      → пульт оператора: выбор игры, пульт игры, реклама, хоткеи
        ├──► /control          → пульт для телефона (сцены, плашки, счёт, тексты, реклама)
        └──◄ agent/            → агент хоткеев: сцены OBS + любые действия HUD
```

Обе игры принимают данные всегда: можно держать открытыми и Dota, и CS2, а в эфир
идёт та, что выбрана на пульте. Внутри оверлея у каждой игры своя страница со своими
стилями (`overlay-dota.html` и `cs2/overlay.html`), поэтому графика одной игры
не может сломать графику другой.

Данные из игры берутся через **Game State Integration** — штатную функцию Dota 2.
Клиент, который *играет* матч, отдаёт данные только по своему герою. Клиент, который
**наблюдает** матч, отдаёт данные по всем десяти игрокам. Поэтому нужен отдельный
компьютер или хотя бы отдельный аккаунт наблюдателя.

## Что нужно один раз настроить

### 1. Node.js

Node.js 18 или новее с nodejs.org (LTS). Проверка: `node -v` в командной строке.

### 2. Запуск сервера

Двойной клик по **start.bat**. При первом запуске он сам поставит зависимости.
В окне появятся адреса, в том числе для других ПК в сети:

```
Оверлей для OBS      http://localhost:3000/overlay.html?obs=1
Пульт оператора      http://localhost:3000/control.html
Пульт для телефона   http://localhost:3000/control
С других ПК в сети   http://192.168.1.10:3000/control
```

Окно должно быть открыто весь эфир. При первом запуске Windows спросит про
брандмауэр — разрешите доступ в **частных** сетях, иначе пульт комментатора
и агент хоткеев с других ПК не достучатся.

### 3. Подключение Dota 2

Скопируйте `config/gamestate_integration_arena.cfg` в папку:

```
...\Steam\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\
```

Папки `gamestate_integration` может не быть — создайте её сами.

В Steam: правый клик по Dota 2 → Свойства → Параметры запуска → `-gamestateintegration`.
Перезапустите игру.

Пример конфига (он же лежит в `config/`):

```
"Arena Tournament HUD"
{
    "uri"       "http://localhost:3000/gsi"
    "timeout"   "5.0"
    "buffer"    "0.1"
    "throttle"  "0.1"
    "heartbeat" "10.0"
    "data"
    {
        "provider"  "1"
        "map"       "1"
        "player"    "1"
        "hero"      "1"
        "abilities" "1"
        "items"     "1"
        "draft"     "1"
        "buildings" "1"
        "wearables" "0"
    }
    "auth"
    {
        "token" "arena-hud"
    }
}
```

Если Dota и сервер на разных ПК — в `uri` впишите IP компьютера с сервером.
Порт и токен должны совпадать с `config/server.json`.

### 3б. Подключение CS2

Скопируйте `config/cs2/gamestate_integration_arena.cfg` в папку:

```
...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
```

Именно `game\csgo\cfg`. Параметры запуска не нужны: CS2 включает интеграцию сама,
когда видит файл. Перезапустите игру. В файле адрес `http://127.0.0.1:3000/gsi/cs2` —
тот же сервер и порт, что у Доты.

> Если раньше стоял отдельный CS2-HUD на порту 3001 — замените его `.cfg` этим
> и не запускайте старый сервер: всё теперь в одном.

В консоли наблюдателя CS2 спрячьте родной интерфейс, кроме ленты убийств:

```
cl_draw_only_deathnotices 1
```

Радар HUD не рисует — если нужен, используйте отдельную программу-радар (например,
Boltobserv) отдельным источником в OBS. Камера переключается клавишами 1–9, 0 — номер
на карточке игрока совпадает с клавишей.

### 4. OBS

Источник **Браузер**:

| Поле | Значение |
|---|---|
| URL | `http://localhost:3000/overlay.html?obs=1` |
| Ширина × высота | 1920 × 1080 |
| Пользовательский CSS | оставить только `body { background-color: rgba(0,0,0,0) }` или очистить |
| Выключать источник, когда не виден | снять галочку |
| Обновлять при активации сцены | снять галочку |
| **Управлять звуком через OBS** | **поставить галочку** — звук рекламы и фраз героев идёт из этого источника |

Источник с игрой кладите **под** браузер-источник. Адрес тот же, что был у Dota-HUD,
— перенастраивать OBS не нужно, только поставить галочку звука.

Только этот источник считается «основным»: у него есть звук, и только он ведёт рекламу.
Превью в пульте и оверлей, открытый в обычной вкладке браузера, звука не дают. Не держите
два источника с `overlay.html?obs=1` в разных сценах одновременно — звук задвоится.

### 5. Агент хоткеев (по желанию)

Нужен, если сцены OBS хочется переключать прямо из игры, а OBS стоит на другом ПК.
Настройка — в разделе «Хоткеи прямо из игры» ниже.

## Как этим пользоваться

### Пульт оператора — `control.html`

Сверху — **выбор игры в эфире** (Dota 2 / CS2) и статусы: идут ли данные из каждой игры
(точка у названия) и подключён ли OBS-оверлей. Переключение игры — двумя нажатиями:
первое спрашивает «Точно?», второе в течение 3 секунд переключает. Хоткея у этого
действия на пульте нет специально: случайное нажатие посреди эфира сменило бы весь оверлей.

Ниже — вкладки:

| Вкладка | Что там |
|---|---|
| **Пульт игры** | пульт той игры, что в эфире: для Dota — как раньше, для CS2 — пульт CS2 (стороны, карты серии, экономика…) |
| **Реклама** | очередь, ролики, переходы, превью эфира (см. «Реклама в паузе») |
| **Пик героя** | анимация пика: вкл/выкл, фраза героя, громкость, проверка (только Dota) |
| **Хоткеи** | все хоткеи для текущей игры и список действий для Stream Deck |

Когда в игре пауза, под шапкой появляется полоса «Пауза в игре — можно запустить рекламу»
с кнопкой. Пока идёт реклама — полоса с названием ролика, прогрессом и кнопками
«Следующий ролик» и «Остановить».

Названия команд и счёт серии общие: в Доте команда A стоит за Radiant или Dire
(кнопка «Команды поменялись сторонами» меняет только это), в CS2 — слева.

Сцены пульта Dota:

| Кнопка | Что в эфире |
|---|---|
| **Игра** | графика поверх игры; во время драфта сама показывает экран пиков и банов |
| **Скоро начнём** | заставка с заголовком и обратным отсчётом |
| **Перерыв** | заставка перерыва |
| **Сетка** | турнирная сетка |
| **Итог карты (заставка)** | крупная надпись с победителем и счётом серии, вручную |
| **Таблица счёта (живая)** | все десять игроков прямо из игры |
| **Две игры**
- [ ] Режим 7 (CS2) при выбранной на пульте Dota — у CS2 на пульте загорается точка, в эфире по-прежнему Dota
- [ ] Нажать «CS2» — кнопка спрашивает «Точно?», второе нажатие переключает; оверлей плавно сменился на CS2
- [ ] Названия команд и счёт серии те же; на телефоне появились CS2-плашки, исчезли Dota-плашки
- [ ] `Alt+R` в CS2 — таблица игроков, в Dota — составы; `Alt+I` в Dota — итоги карты
- [ ] Вернуть Dota — всё, что было включено в Доте, на месте

**Реклама**
- [ ] OBS (или обычная вкладка `overlay.html?obs=1`) открыт — на пульте «OBS-оверлей» зелёный
- [ ] Загрузить ролик MP4 — появились длительность и кадр-превью, ролик в очереди
- [ ] Загрузить переход WebM с альфой, «Проверить» — в точке перекрытия экран закрыт целиком
- [ ] «Запустить рекламу» — переход поверх HUD → ролик → переход → тот же HUD, что был
- [ ] Во время ролика «Остановить» — уходит с выходным переходом
- [ ] Звук ролика слышен в OBS (галочка «Управлять звуком через OBS»), превью в пульте без звука
- [ ] Закрыть OBS-оверлей и нажать «Запустить» — понятная ошибка, ничего не зависло

**Анимация пика**
- [ ] Режим 6. На каждый пик — карточка со стороны пикнувшей команды, таймер и текущий слот не закрыты
- [ ] Перезагрузить оверлей посреди драфта — уже сделанные пики не проигрываются заново
- [ ] Положить `juggernaut.mp3` в `public/assets/heroes/voice/`, «Проверить» несколько раз — при Juggernaut звучит фраза

**Чистый экран** | оверлей полностью прозрачный: ни ленты, ни плашек, ни фона — в OBS только игра |

Хоткеи пульта работают, пока пульт в фокусе (в том числе когда курсор внутри «Пульта игры»)
и курсор не стоит в текстовом поле. Одинаковые действия — на одних клавишах в обеих играх:

| Хоткей | Обе игры | Dota 2 | CS2 |
|---|---|---|---|
| `Alt+1` … `Alt+6` | Игра / Скоро начнём / Перерыв / Сетка / Итог-заставка / Таблица счёта | | |
| `Alt+7` | | | Пики карт |
| `Alt+0` | Чистый экран | | |
| `Alt+H` | Вся графика | | |
| `Alt+K` | Комментаторы | | |
| `Alt+T` / `Alt+N` | Trivia / следующий факт из заготовок | | |
| `Alt+C`, `Alt+↑` / `Alt+↓` | Таймер «скоро начнётся», ±1 минута | | |
| `Alt+A` / `Alt+S` | Реклама: запустить очередь / остановить | | |
| `Alt+R` | | Составы команд | Таблица игроков |
| `Alt+I` | | **Итоги карты** (раньше были на `Alt+R`) | |
| `Alt+P` | | Вероятность победы | |
| `Alt+W` / `Alt+O` | | Полоса золота / Рошан | |
| `Alt+J` | | Повторить анимацию последнего пика | |
| `Alt+M` / `Alt+B` / `Alt+L` | | | История раундов / Экономика / Своя лента убийств |

Те же хоткеи работают на пульте для телефона, если открыть его на ноутбуке.
Любое действие — это и HTTP-запрос для Stream Deck / Touch Portal / Companion:
`http://localhost:3000/api/action/scene-starting`. Полный список — `/api/actions?all=1`
или вкладка «Хоткеи» на пульте.

### Пульт для телефона — `/control`

Открывается с любого телефона, планшета или ноутбука в той же сети:
`http://<IP сервера>:3000/control` (IP сервер пишет в своём окне при запуске).
Права у всех одинаковые: комментатор, режиссёр и оператор видят одно и то же,
любое нажатие сразу уходит в эфир и на все открытые пульты.

Сверху всегда видно, какая игра и что сейчас в эфире, игровое время и проценты. Внизу шесть
вкладок; то, что относится только к одной игре, показывается, когда в эфире эта игра:

| Вкладка | Что там |
|---|---|
| **Эфир** | все сцены HUD крупными кнопками; Dota — вероятность победы, итоги карты; CS2 — таблица игроков, история раундов, «Пики карт» |
| **Плашки** | вся графика, комментаторы, Trivia, таймер; Dota — полоса золота, Рошан, составы; CS2 — экономика, карточки игроков, игрок в камере, своя лента убийств |
| **Матч** | названия команд, счёт серии ±, формат, смена сторон, стадия; Dota — «Сбросить матч» |
| **Тексты** | Trivia с заготовками, имена комментаторов, обратный отсчёт в одно нажатие (5/10/15 мин), текст перерыва, бегущая строка |
| **Реклама** | очередь роликов, «Запустить», «Следующий», «Стоп». Загружать ролики — на пульте оператора |
| **Фон** | фон заставок: файлом или ссылкой, общий или для отдельной сцены, затемнение |

Во время паузы в игре сверху появляется полоса с кнопкой «Запустить» рекламу.

**Заготовки Trivia.** Напишите факт заранее и нажмите «В заготовки». Во время паузы
достаточно нажать «Вывести» у нужной заготовки — она сразу в эфире. Заготовки хранятся
на сервере, их видно со всех устройств.

**Как значок на экране телефона.** В браузере телефона: меню → «Добавить на главный
экран». Пульт будет открываться как отдельное приложение, без адресной строки.

На ноутбуке с широким экраном вкладки не нужны — все разделы видны сразу.
С клавиатуры работают те же хоткеи, что на пульте оператора.

Что важно знать:
- Пульт работает только в локальной сети и без пароля: открыть его может любой,
  кто подключён к той же Wi-Fi. Если сеть общая для зрителей, раздайте отдельную.
- Экран телефона может гаснуть во время эфира — увеличьте время блокировки
  в настройках телефона на время трансляции.
- Если связь пропала, наверху появится красная полоса, пульт переподключится сам.

### Драфт

Экран драфта включается сам, пока игра в стадии выбора героев (сцена «Игра»).
Оверлей рисует ровно то, что присылает игра: пики и баны каждой команды по порядку,
кто сейчас выбирает и пик это или бан — текущий слот подсвечен. Свою логику фаз
оверлей не ведёт, поэтому не может «убежать» от игры.

Таймер по центру — основное время хода. Под названиями команд — их резерв.
Когда основное время вышло, таймер показывает резерв активной команды розовым
с подписью «резервное время». Между пакетами из игры таймер идёт сам, но каждый
пакет его выравнивает; разойтись с игрой больше чем на секунду он не может.
На паузе стоит.

### Фон заставок

На вкладке «Фон» пульта для телефона или в карточке «Фон заставок» у оператора:

- **Загрузить файл** — JPG, PNG, WebP или видео MP4/WebM до 20 МБ. Файл сохраняется
  в `public/assets/backgrounds/` на ПК с сервером, интернет для него не нужен.
- **Ссылка** — прямая ссылка на картинку или видео. Пульт сначала проверяет, что она
  открывается. Для эфира надёжнее загрузить файл: ссылка зависит от интернета на ПК с OBS.
- **Для какой сцены** — «Все заставки» задаёт общий фон; у любой сцены (скоро начнём,
  перерыв, сетка, итог-заставка, таблица счёта, итоги карты, драфт) можно поставить свой,
  он важнее общего. «Вернуть стандартный» снимает фон с выбранной сцены.
- **Затемнение** 0–80 % — чтобы текст читался на светлой картинке.

Загруженные файлы видны списком: любой можно поставить заново или удалить.

### Реклама в паузе

Вкладка **«Реклама»** на пульте оператора.

**Ролики.** Перетащите файлы в поле «Ролики» (или нажмите на него). Можно и проще —
скопировать файлы в папку `public/assets/ads/clips` (переходы — в `public/assets/ads/transitions`):
сервер раз в 3 секунды смотрит в эти папки, новые файлы сам добавляет в список и в очередь,
а удалённые из папки убирает. Пульт откроет их, снимет длительность и кадр-превью. Подходят MP4 с видео
H.264 и звуком AAC и WebM, до 1 ГБ на файл (лимит — `"ads": { "maxUploadMb": 1024 }` в
`config/server.json`). Файлы ложатся в `public/assets/ads/` на ПК с сервером. После загрузки
пульт открывает ролик у себя: снимает длительность и кадр для превью и **проверяет, что
видео вообще воспроизводится** — OBS построен на том же Chromium, поэтому если пульт файл
не открыл, OBS его тоже не сыграет, и пульт сразу об этом скажет.

У каждого ролика: название, «в очереди», свой переход (или «по умолчанию», или «без
перехода»), громкость, «▶ Только этот ролик» (запустить сразу его одного), удаление.

**Переходы (stinger).** Видео, которое играет поверх эфира в начале и в конце рекламы.
Лучше всего — WebM с прозрачностью (VP9 + альфа): тогда в начале перехода виден эфир,
потом переход закрывает экран, а когда он уходит — уже идёт ролик. У перехода есть
**точка перекрытия** в миллисекундах — момент, когда переход полностью закрывает экран.
Именно в этот момент под ним включается ролик (на входе) и возвращается эфир (на выходе).
Кнопка «Проверить» проигрывает переход в пульте и замирает на секунду в точке перекрытия:
кадр в этот момент должен быть закрыт целиком.

**Очередь.** Ролики играют по порядку (стрелки ↑↓ меняют порядок). «Между роликами»:
переход или прямая склейка.

**Как идёт показ:**

```
переход ──(точка перекрытия)──► ролик 1 ──► [переход или склейка] ──► ролик 2 …
                                                     ──► переход ──(точка перекрытия)──► эфир
```

Пока идёт реклама, HUD под ней никуда не девается — когда реклама закончится, будет
та же сцена, что и до неё. «Следующий ролик» — пропустить текущий. «Остановить» —
досрочно, но с выходным переходом. Если ролик не воспроизводится или завис дольше
8 секунд, он пропускается, а пульт показывает ошибку — эфир не останется на чёрном.

Важно:
- Реклама запускается только при подключённом **OBS-оверлее** (`overlay.html?obs=1` в
  OBS) — на пульте его статус справа сверху. Иначе кнопка вернёт ошибку.
- Звук рекламы идёт из браузер-источника OBS — нужна галочка «Управлять звуком через OBS».
- Автоматического запуска на паузе нет: пульт только подсказывает.

**Перекодировать ролик**, если пульт сказал, что не может его открыть (часто это H.265/HEVC
с телефона или ProRes):

```
ffmpeg -i вход.mov -c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart ролик.mp4
```

**Сделать переход с прозрачностью** из последовательности PNG с альфой (так их отдают
After Effects, Premiere, DaVinci):

```
ffmpeg -framerate 60 -i кадр_%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 4M -auto-alt-ref 0 переход.webm
```

или из MOV с альфой (ProRes 4444): `ffmpeg -i переход.mov -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 4M -auto-alt-ref 0 переход.webm`.

### Анимация пика

Во время драфта Dota при каждом новом пике на оверлее выезжает карточка героя со стороны
команды, которая его выбрала: анимированный портрет героя, название команды, номер пика,
имя героя — и звучит фраза героя, если она есть. Карточка стоит в полосе между пятым пиком
и рядом банов, поэтому не закрывает ни таймер хода, ни резерв, ни подсветку текущего слота.

- Работает и с обычным GSI, и с кастомкой Arena 5x5. В All Pick и других режимах без
  драфта карточка появляется, когда герой появился у игрока.
- Уже готовый драфт не проигрывается: ни после перезапуска сервера или перезагрузки
  оверлея, ни при подключении посреди драфта. Повторные пакеты и «чужой» второй источник
  данных повторов не дают. Если пики приходят пачкой — карточки идут по очереди.
- Анимированный портрет берётся с серверов Valve (`…/videos/dota_react/heroes/renders/<герой>.webm`).
  Если не загрузился — статичный портрет с плавным приближением. Без интернета — фирменная подложка.
- Вкладка **«Пик героя»** на пульте: вкл/выкл, фраза героя, громкость, «Проверить на
  случайном герое», «Повторить последний пик» (`Alt+J`).

**Фразы героев.** Положите в `public/assets/heroes/voice/` файлы `.mp3`, `.ogg` или `.wav` с
**внутренним** именем героя (как в `npc_dota_hero_<имя>`): `juggernaut.mp3`, `antimage.ogg`,
`nevermore.ogg` (Shadow Fiend), `zuus.ogg` (Zeus), `wisp.ogg` (Io). Нет файла — анимация без звука.

Как достать фразы из игры: откройте `...\dota 2 beta\game\dota\pak01_dir.vpk` в программе
**Source 2 Viewer** (ValveResourceFormat, бесплатная, github.com/ValveResourceFormat). Фразы
лежат в `sounds/vo/<герой>/`. Подходящие для пика обычно содержат в названии `pick`
или `spawn` — точные имена у героев разные, послушайте пару вариантов прямо в программе. Выделите файл →
Export — получится `.wav` или `.mp3`. Переименуйте в `<внутреннее имя героя>.<расширение>`.
Это звуки из самой игры — используйте их только на трансляции турнира.

### Итоги карты

Когда карта заканчивается (стадия `POST_GAME` или в данных появился победитель),
сервер **замораживает** последний полный снимок и сам выводит плашку итогов:
победитель, счёт по убийствам, длительность и по каждому игроку — герой, уровень,
K/D/A, нетворс, GPM/XPM, ластхиты/денаи, урон по героям и строениям, предметы.

Плашка держится, пока её не скроют или пока не начнётся новая карта (сменится
`matchid`). Итоги сохраняются в `data/match.json`, так что и перезапуск сервера
их не теряет. Если включить плашку до конца карты, она покажет текущую статистику
с подписью «Карта идёт».

Сразу после окончания сервер начинает спрашивать OpenDota: матч там появляется
с задержкой, поэтому попытки идут с нарастающими паузами (настраиваются в
`config/server.json`). Что пришло — дописывается в пустые поля, без пустых ячеек:
колонка, по которой нет данных ни у кого, просто не показывается. Статус виден
на пульте комментатора. Матчи из закрытых лобби могут в OpenDota не появиться
вовсе — тогда остаются данные из игры, это нормально.

Автопоказ итогов можно выключить: `"results": { "autoShow": false }`.

### Вероятность победы

Считается на сервере по данным из игры: разница золота, опыта, живых строений
и убийств. Чем дальше в игру, тем меньше весит та же разница в золоте и опыте.
Результат зажат в 3–97%: в доте камбэки случаются.

**Это эвристическая оценка, а не предсказание Dota Plus** и не обученная модель.
Коэффициенты подобраны вручную и лежат в `config/probability.json`:

```json
{
  "bias": 0,
  "netWorth":   { "weight": 0.18, "per": 1000, "timeScaleMin": 20 },
  "experience": { "weight": 0.10, "per": 1000, "timeScaleMin": 20 },
  "buildings":  { "weight": 0.12, "towerValue": 1, "barracksValue": 2 },
  "kills":      { "weight": 0.03, "timeScaleMin": 20 },
  "clamp":      { "min": 3, "max": 97 }
}
```

Файл можно править на ходу — сервер перечитает его сам. Разбивка, сколько дал
каждый признак, видна по адресу `/api/match`. Ориентиры при нынешних значениях:
5k золота на 10-й минуте — около 65%, 15k на 30-й при разнице в опыте и башнях —
около 85–90%.

### Сравнение «было → стало»

Каждый раз, когда комментатор включает плашку, сервер запоминает игровое время и
процент. Если среди прошлых включений этой карты есть сделанное **5 и более игровых
минут** назад, под плашкой появляется строка:

```
10:00 → 25:30   ИТ-факультет 42% → 58%   ▲16
```

Берётся самое свежее из подходящих включений. Время считается по игровым часам —
паузы не входят. Если подходящего снимка нет, строки нет. Порог — в
`config/server.json`, `"comparison": { "minAgeSec": 300 }`. Новая карта стирает снимки.

Если хочется, чтобы сравнение было доступно, даже когда плашку давно не включали,
задайте `"autoSnapshotEverySec": 300` — сервер будет сам делать снимок каждые
5 игровых минут.

## Хоткеи прямо из игры (агент)

Папка `agent/` — отдельная маленькая программа для ПК, где запущена игра. Она слушает
клавиатуру даже когда игра в фокусе и:

- переключает сцены OBS через obs-websocket (OBS может стоять на другом ПК);
- выполняет любое действие HUD: плашки, сцены HUD, рекламу (`"action"`, список — `/api/actions?all=1`).

Нажатия не перехватываются — игра их тоже получает, поэтому сочетания взяты такие,
которые Dota не использует.

### Настройка

1. В OBS: Инструменты → Настройки сервера WebSocket → включить, порт `4455`,
   задать пароль. Кнопка «Показать сведения о подключении» покажет IP.
2. Скопируйте папку `agent/` на ПК с Dota (если это другой компьютер) и откройте
   `agent/config.json`:

```json
{
  "obs": { "url": "ws://192.168.1.20:4455", "password": "пароль из OBS" },
  "hud": { "url": "http://192.168.1.10:3000" },
  "reconnect": { "minSec": 1, "maxSec": 15 },
  "hotkeys": [
    { "keys": "Ctrl+Alt+F1", "scene": "Игра" },
    { "keys": "Ctrl+Alt+F2", "scene": "Драфт" },
    { "keys": "Ctrl+Alt+F3", "scene": "Камера комментаторов" },
    { "keys": "Ctrl+Alt+F4", "scene": "Повтор" },
    { "keys": "Ctrl+Alt+F5", "scene": "Перерыв" },
    { "keys": "Ctrl+Alt+F6", "scene": "Скоро начнём" },
    { "keys": "Ctrl+Alt+F7", "scene": "Сетка" },
    { "keys": "Ctrl+Alt+F8", "scene": "Итоги" },
    { "keys": "Ctrl+Alt+F9",  "action": "toggle-probability" },
    { "keys": "Ctrl+Alt+F10", "action": "toggle-mapResults" },
    { "keys": "Ctrl+Alt+F11", "action": "ads-play" },
    { "keys": "Ctrl+Alt+F12", "action": "ads-stop" }
  ]
}
```

`"action"` — любое действие из `/api/actions?all=1`: `scene-starting`, `toggle-hud`,
`toggle-stats` (CS2), `trivia-next` и т.д. Старый формат `"hud": "probability"` тоже работает.

3. Запустите **agent/list-scenes.bat** — он покажет точные имена сцен вашего OBS.
   Скопируйте их в `scene` один в один, с регистром и пробелами.
4. Запустите **agent/start-agent.bat**. В окне будет список хоткеев и строка
   «OBS подключён». Окно можно свернуть.

Агент сам переподключается, если OBS перезапустили или пропала сеть, и пишет
в окно, что происходит: какие сцены переключены, каких сцен нет в OBS, недоступен
ли сервер HUD.

### Если хоткеи не срабатывают в игре

- Запустите Dota в режиме **«Окно без рамки»** (Настройки → Видео → Режим отображения).
  В эксклюзивном полноэкранном режиме глобальные хоткеи на части систем не доходят.
- Агент и Dota должны работать с одинаковыми правами: если Dota запущена от
  администратора, агента тоже запускайте от администратора — иначе Windows
  не отдаёт ему нажатия.
- Сочетание может перехватывать драйвер видеокарты (у Intel бывают Ctrl+Alt+F12
  и Ctrl+Alt+стрелки) — поменяйте его в `config.json`.

### Если Dota и OBS на одном ПК

Агент не обязателен: в OBS есть свои глобальные хоткеи (Настройки → Горячие клавиши
→ «Переключиться на сцену»). Они тоже работают при игре в фокусе, если Dota в режиме
«Окно без рамки». Агент тогда нужен только для плашек HUD — или включайте их
с пульта комментатора.

### Проверка без OBS и без клавиатуры

```
npm run mock:obs                                   (в папке проекта: имитатор OBS)
node agent.js --list-scenes                        (в папке agent)
node agent.js --simulate "Ctrl+Alt+F3"             выполнить хоткей без нажатия
node agent.js --no-hook                            только держать связь с OBS
```

## Что игра отдаёт наблюдателю, а что нет

| Данные | Откуда |
|---|---|
| счёт, время, стадия, победитель, matchid, пауза | GSI, `map` |
| K/D/A, нетворс, GPM/XPM, ластхиты/денаи | GSI, `player` |
| герой, уровень, жив ли | GSI, `hero` |
| предметы и нейтралка | GSI, `items` |
| строения обеих сторон | GSI, `buildings` (наблюдателю — по обеим) |
| урон по героям и строениям, лечение | в GSI наблюдателя есть не всегда → OpenDota |
| суммарный опыт героя | поле `hero.xp` есть не во всех версиях клиента → иначе считаем как XPM × время |
| официальная вероятность Dota Plus | в GSI её нет → своя оценка (см. выше) |

Сервер ничего не выдумывает: если поля нет, колонка скрывается, а модель
вероятности пропускает признак. Что реально пришло, видно в `/api/state`.

## Как всё протестировать

### Без игры — имитатор

Запустите сервер, затем **start-test-data.bat** и выберите режим. На пульте выберите
ту же игру, что имитируете:

| Режим | Что проверяет |
|---|---|
| 1 — Dota: матч в разгаре | графика поверх игры, вероятность |
| 2 — Dota: драфт | Captain's Mode по фазам: баны и пики по очереди, основное и резервное время; на 3-м и 13-м ходу капитан тратит резерв |
| 3 — Dota: конец карты | итоги: 15 с игры, затем `POST_GAME`, затем урезанные пакеты, как после выхода наблюдателя в меню |
| 4 — Dota: быстрая игра ×10 с паузами | сравнение вероятности за 5+ минут, исключение пауз, подсказка «Пауза — можно запустить рекламу» |
| 5 — Dota: другой matchid | сброс итогов при новой карте |
| 6 — Dota: быстрый драфт | анимация пика (каждый запуск — новый номер матча, чтобы пики не считались «уже виденными») |
| 7 — CS2: матч с первого раунда | табло, карточки, экономика, бомба |
| 8 — CS2: конец первой половины | смена сторон по игрокам |
| 9 — CS2: разминка, затем матч | разминка не портит статистику |
| 10 — CS2: быстрый прогон ×4 | весь матч за несколько минут |

Те же режимы из командной строки: `npm run mock`, `npm run mock:end`,
`npm run mock:fast`, `node tools/mock-gsi.js --match=7900000002`.
Дополнительно: `--winner=dire`, `--no-damage` (без урона в данных — проверить догрузку из OpenDota).
Драфт быстрее: `node tools/mock-gsi.js --draft --speed=3`.
CS2: `npm run mock:cs2`, `npm run mock:cs2:half`, `node tools/mock-cs2.js --speed=4`.
Анимация пика без игры: кнопка «Проверить на случайном герое» на вкладке «Пик героя»
или `POST /api/pickfx/test?hero=juggernaut&side=dire`.

Пакеты имитатора помечены, и сервер не даёт им смешаться с игрой: пока идут данные из
настоящей Dota, имитатор игнорируется, а на пультах появляется предупреждение.

### Чек-лист ручной проверки

**Конец игры → итоги**
- [ ] Режим 3. Через ~15 секунд в оверлее сама появляется плашка «Победа …»
- [ ] Ещё через 7 секунд имитатор шлёт пустые пакеты — плашка остаётся с теми же цифрами
- [ ] Открыть оверлей в новой вкладке — итоги видны сразу
- [ ] Перезапустить сервер — итоги на месте (`/api/health` → `"resultsFrozen": true`)
- [ ] На пульте комментатора снять «Итоги карты» — плашка плавно уходит; включить — возвращается
- [ ] Режим 5 (другой matchid) — итоги сбрасываются, галочка «Итоги карты» снимается сама

**Вероятность: включение и выключение**
- [ ] Режим 1. На пульте комментатора включить «Вероятность победы» — плашка выезжает за ~0,4 с
- [ ] Проценты меняются плавно, сумма всегда 100
- [ ] Галочка совпадает на двух открытых пультах и после перезагрузки страницы
- [ ] Выключить — плашка плавно уходит

**Сравнение через 5+ минут**
- [ ] Режим 4. Включить вероятность, выключить
- [ ] Подождать около минуты (это 5+ игровых минут; паузы имитатора не считаются), включить снова —
      под плашкой строка «мм:сс → мм:сс … ▲/▼N»
- [ ] Выключить и сразу включить — сравнение остаётся с тем же исходным снимком,
      пока не появится более свежий снимок старше 5 минут
- [ ] «Сбросить матч» — после него при включении строки сравнения нет

**Пульт с телефона**
- [ ] Телефон в той же Wi-Fi, открыть `http://<IP сервера>:3000/control` — обе точки сверху зелёные
- [ ] Нажать «Перерыв» — в оверлее заставка, на втором открытом пульте кнопка тоже подсвечена
- [ ] Сохранить две заготовки Trivia, вывести одну — плашка в эфире, заготовка помечена «В эфире»
- [ ] «Убрать все плашки» — в эфире осталась только верхняя лента
- [ ] Выключить сервер — на телефоне красная полоса; включить — пульт переподключился сам

**Драфт на имитаторе**
- [ ] Режим 2 (или `--draft --speed=3`). Сверить с окном имитатора: каждый ход «Radiant банит …» появляется на оверлее в слоте этой команды
- [ ] Текущий слот подсвечен у той команды, что ходит; подпись «… банит» / «… выбирает героя»
- [ ] На 3-м ходу основное время доходит до 0:00 — таймер становится розовым «резервное время», резерв Radiant под названием уменьшается
- [ ] После 24 ходов — «Время стратегии»

**Драфт на живом лобби** (Captain's Mode, наблюдатель в слоте вещателя, не через DotaTV)
- [ ] Поставить оверлей рядом с окном игры и пройти весь драфт: каждая фаза, каждый пик и бан совпадают
- [ ] Таймер отличается от игрового не больше чем на 1 секунду
- [ ] Дождаться, когда капитан уйдёт в резерв — на оверлее «резервное время» и тот же остаток, что в игре
- [ ] Если что-то не совпало — включить запись пакетов (раздел «Диагностика») и прислать файл

**Фон заставок**
- [ ] Вкладка «Фон» → «Загрузить файл» → картинка. На сцене «Скоро начнём» она за текстом
- [ ] Ползунок затемнения — фон темнеет в превью и в эфире
- [ ] Для «Перерыва» поставить другой фон ссылкой — у перерыва свой, у остальных общий
- [ ] Неверная ссылка — понятная ошибка, фон не меняется
- [ ] Файл больше 20 МБ или .gif — понятная ошибка
- [ ] Перезапустить сервер — фоны на месте

**Чистый экран**
- [ ] Включить Trivia, вероятность, комментаторов. Нажать «Чистый экран» — в OBS только игра, без единого элемента
- [ ] Вернуть «Игра» — всё, что было включено, вернулось

**Хоткеи сцен**
- [ ] `npm run mock:obs` в одном окне, в `agent/config.json` адрес `ws://127.0.0.1:4455`
- [ ] `node agent.js --simulate "Ctrl+Alt+F3"` — в окне имитатора «→ сцена «Камера комментаторов»»
- [ ] С настоящим OBS: запустить агента, в игре нажать `Ctrl+Alt+F1…F8` — сцены переключаются
- [ ] Закрыть OBS — агент пишет «связь потеряна» и пробует снова; открыть — «OBS подключён»
- [ ] `Ctrl+Alt+F9` / `F10` — плашки HUD появляются и уходят

### С Dota 2 — одиночный тест

1. Запустите сервер.
2. Лобби: **зрители — вкл**, боты, старт.
3. Зайдите **как наблюдатель**.
4. На пульте загорится зелёный кружок «игра».
5. Доиграйте или сдайте карту — должны появиться итоги.

### Диагностика

- `/api/health` — идут ли данные, номер матча, заморожены ли итоги
- `/api/state` — склеенный снимок из игры целиком
- `/api/match` — вероятность с разбивкой по признакам, снимки, статус OpenDota

**Запись пакетов из игры.** Если оверлей расходится с игрой, включите запись в
`config/server.json` и перезапустите сервер:

```json
"gsiLog": { "enabled": true, "onlyDraft": true, "compact": true }
```

Пакеты пишутся в `data/gsi-log/gsi-ДАТА-ВРЕМЯ.jsonl` (путь видно в окне сервера и в
`/api/health`). `onlyDraft` — только стадия драфта, `compact` — только время, стадия
и драфт, без игроков: так файл занимает мегабайты, а не сотни. В каждой строке —
время, сам пакет и что сервер с ним сделал (`accepted` или причина, почему проигнорирован).
После разбора выключите запись обратно.

Открыть `/gsi` в браузере нельзя — увидите `Cannot GET /gsi`. Это нормально:
туда принимаются только POST-запросы от игры.

## Если не работает

**На пультах жёлтая полоса «Одновременно идут данные из игры и из имитатора».**
Открыто окно `start-test-data.bat`. Закройте его. Сервер уже игнорирует имитатор,
пока идут данные из игры, но лучше не держать их вместе.

**Жёлтая полоса «Данные приходят сразу по двум матчам».** Файл `.cfg` лежит у двух
клиентов Dota, которые смотрят разные матчи. Оставьте его только на ПК наблюдателя.
Сервер держится за первый матч и игнорирует второй.

**Драфт на оверлее отстаёт от игры на десятки секунд.** Наблюдатель смотрит через
DotaTV с задержкой трансляции. Зайдите в лобби в слот вещателя/наблюдателя без
задержки или уменьшите задержку в настройках лобби.

**В окне `start.bat` ошибки вида `' к:' is not recognized…`, `'fail' is not recognized…`.**
Так `cmd.exe` на части версий Windows читает `.bat` с русским текстом в кодировке UTF-8:
сбивается позиция в файле, и выполняются обрывки строк. Сейчас все `.bat` в проекте
написаны только латиницей, а русский текст выводит сам Node — ошибка не повторится.
Если видите её снова, значит, запущен старый `start.bat`: замените файлы из нового архива.
Обходной путь на любой версии: открыть `cmd` в папке проекта и ввести `npm install`,
затем `node server\index.js`.

**`Node.js not found on this PC`.** На этом компьютере не установлен Node.js или
установщик не добавил его в PATH. Поставьте LTS-версию с nodejs.org и перезапустите
окно (а лучше и компьютер).

**Итоги не появились после конца карты.**
- Наблюдатель вышел из матча раньше, чем игра перешла в `POST_GAME`, и данных
  о победителе так и не пришло. Включите «Итоги карты» вручную — покажется
  последний полученный снимок со статистикой (без победителя). Чтобы не попадать
  в эту ситуацию, наблюдателю не выходить из матча до экрана итогов.
- `"autoShow": false` в `config/server.json`.

**Плашка вероятности не появляется.** До горна она не показывается, после конца
карты — тоже. Проверьте, что в `/api/match` есть `probability`.

**Оверлей в OBS чёрный.** Нужен источник «Браузер» с URL, а не захват окна.

**`Порт 3000 занят` при запуске.** Открыт второй сервер — например, старый Dota-HUD или
CS2-HUD. Закройте его окно: теперь обе игры работают в одном сервере.

**Реклама: «Основной оверлей не подключён».** В OBS нет источника `overlay.html?obs=1`,
OBS закрыт или источник выключен. Проверьте точку «OBS-оверлей» справа сверху на пульте.

**Ролик загрузился, но пульт пишет, что браузер его не открыл.** Кодек, который браузер не
понимает (H.265/HEVC, ProRes). Перекодируйте командой из раздела «Реклама в паузе».

**Ролик играет без звука.** В свойствах браузер-источника OBS не стоит галочка «Управлять
звуком через OBS» или источник заглушён в микшере OBS.

**Переход «моргает» эфиром перед роликом.** Точка перекрытия стоит раньше, чем переход
закрывает экран. Увеличьте её и проверьте кнопкой «Проверить».

**CS2: нет данных.** `.cfg` не в `game\csgo\cfg`, в нём старый порт 3001 или токен не
совпадает с `config/server.json`. CS2 нужно перезапустить после копирования `.cfg`.

**Кружок «игра» не горит.**
- Клиент играет, а не наблюдает.
- Нет параметра запуска `-gamestateintegration`.
- `.cfg` не в той папке или назван не `gamestate_integration_*.cfg`.
- Порт или токен в `.cfg` не совпадают с `config/server.json`.
- Брандмауэр блокирует порт 3000.

**Пульт комментатора не открывается с другого ПК.** Брандмауэр Windows на ПК с
сервером: разрешите Node.js в частных сетях, сеть должна быть помечена как частная.

**Иконки героев пустые.** Нужен интернет (серверы Valve). На месте иконок будет
фирменная подложка — эфир не сломается.

**Перенос со старых версий.** При первом запуске сервер сам переводит `data/control.json`
в новый формат (копия старого — в `data/backup/`). Чтобы забрать настройки CS2-HUD
(стороны, плашки, карты серии, таймер, заготовки Trivia), до первого запуска положите
его `data/control.json` сюда как `data/cs2-control.json`.

## Что менять под свой турнир

- Цвета — `:root` в `public/css/overlay.css` (`--brand-a`, `--brand-b`, `--lime`); у CS2 — `public/cs2/css/overlay.css`.
- Хоткеи пультов — `public/js/hotkeys.js`.
- Карточка пика — `public/css/shell-overlay.css` (`.pickfx__card`), длительность — `DURATION` в `public/js/shell-overlay.js`.
- Положение плашки вероятности — `.winprob` в `overlay.css`.
- Колонки итогов — массив `MR_COLUMNS` в `public/js/overlay.js`.
- Модель вероятности — `config/probability.json`, без перезапуска.
